# BE STRONGER V10 — Cloud-ready prototype

This package is a frontend prototype prepared for a production backend.

## Important
The app is NOT connected to a real cloud database yet. The API URL field only stores a future endpoint locally.

## Production requirements
- HTTPS only
- Managed authentication
- Server-side authorization by user/coach role
- Database with row-level access controls
- Encrypted transport
- Private storage for progress photos
- Server-side validation of all profile/program/check-in data
- Backups and audit logs

## API contract
See `index.html` and `data-schema.json` for the proposed resource structure.
